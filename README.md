#  Blood Wave - Blood Donation Management System

Blood Wave is a Full Stack Blood Donation Management System developed using HTML, CSS, JavaScript, Node.js, Express.js, and MySQL.

This project helps users find blood donors based on blood group, city, and pincode. It also includes secure authentication using JWT and password reset functionality using email verification.

---

# Features

User Registration  
Donor Registration  
Secure Login Authentication  
JWT Authentication  
Forgot Password via Email  
Reset Password System  
Search Donors by Blood Group  
Search Donors by City & Pincode  
Responsive UI Design  
MySQL Database Integration
